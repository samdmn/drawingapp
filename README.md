# Logiciel de dessin

Simple logiciel de dessin développé lors d'un TP d'IHM.

## 🖥️ Technologies

- **Langage :** Python  
- **Bibliothèque :** PyQt5  
- **Plateforme :** Cross-platform (Windows, Linux, macOS)

## 🚀 Tester l'appli

### Pré-requis

Assurez-vous que Python and PyQt5 soient installés.

Clonez ce dépôt et lancez le programme :

```bash
git clone https://github.com/samdmn/drawingapp.git
cd drawingapp
python Dessin.py
```
